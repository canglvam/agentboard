# AgentBoard — the .ai reputation board

Agent ID holders check in once a day (free, gas only), build a public streak
tied to their soulbound `.ai` name, claim one free commemorative badge NFT,
and tip other Agent ID holders. The Agent ID **is** the account: no email,
no signup, no off-chain database.

Built for the Binance Wallet × BNB Chain **Agent ID Hackathon**
(60,000 USDC prize pool; submissions 2026-11-18 → 2026-12-09 08:00 UTC).
Full research + plan: `../PLAN.md`.

## How Agent ID is used (the jury's "depth" criterion)

- **Access control:** every action — `checkIn()`, `claimBadge()`, `tip()` — is
  gated on-chain by `balanceOf > 0` on the Agent ID registry
  (`0x60b9262456de011f7d15a54cdd8c48baaa8b022f` on BNB Chain mainnet).
- **Identity:** streaks and badges accrue to the soulbound name, which cannot
  be transferred or sold, so reputation can't be bought by moving an NFT.
- **Payments:** tips can only go *to* Agent ID holders (recipient checked
  on-chain); the `.ai` name is the payment address. 100% forwarded, no fee.
- Display names (`.ai`) are resolved **off-chain** from token metadata
  (`tokenURI`); the contract never stores names and this is not a
  wallet-lookup-by-name tool.

## Contract

`contracts/AgentBoard.sol` (Solidity ^0.8.24, OpenZeppelin 5):

| Function | Notes |
|---|---|
| `checkIn()` | Once per UTC day per holder; streak +1 on consecutive days, reset to 1 after a missed day. Emits `CheckIn`. |
| `claimBadge()` | One free ERC-721 badge per holder (on-chain SVG metadata, no IPFS). Emits `BadgeClaimed`. |
| `tip(address to, string message) payable` | Sender + recipient must hold an Agent ID; forwards 100% immediately. Emits `Tip`. |
| `hasAgentId(address)` / `getStats(address)` | Read-only views. |
| `pause()` / `unpause()` | Owner-only emergency pause. The **only** owner power. |

There is **no withdraw function** — the contract never holds user funds.
Constructor takes the registry address (real registry on mainnet,
`MockAgentId` on testnet).

## Deploy (testnet)

```bash
# 1. Generate a fresh testnet deployer (mode 600, outside the repo):
node scripts/gen-keypair.js ~/workspace/binance-agent-id-hackathon/deployer/testnet-deployer.json "agentboard testnet deployer"
# 2. Fund it with tBNB from the BSC testnet faucet (0.3 tBNB/day).
#    The official faucet needs a captcha and 0.002 BNB on BSC mainnet in the
#    receiving address; see https://testnet.bnbchain.org/faucet-smart
# 3. Deploy (key via env, never committed):
node -e "const fs=require('fs');const k=JSON.parse(fs.readFileSync(process.env.HOME+'/workspace/binance-agent-id-hackathon/deployer/testnet-deployer.json'));require('child_process').execSync('npx hardhat run scripts/deploy.js --network bscTestnet',{stdio:'inherit',env:{...process.env,PRIVATE_KEY:k.privateKey}})"
# 4. E2E (same PRIVATE_KEY env + TEST_WALLETS_FILE optional):
node -e "...same wrapper... 'npx hardhat run scripts/e2e-testnet.js --network bscTestnet'"
# 5. Verify on BscScan (needs BSCSCAN_API_KEY):
BSCSCAN_API_KEY=... npx hardhat run scripts/verify.js --network bscTestnet
```

## Safety / red lines (full checklist in `docs/AUDIT-NOTES.md`)

No QR-code login, no session storage, no bypassed transaction confirmations,
no bundled transfers, no fee skimming (tips 100%), owner powers disclosed,
no "Binance"/"BNB" in the project/token/domain name, no credential
collection, no return promises, money-movement warning shown in the UI,
no name→wallet lookup tool.
